## Content

**Quality of thought** is not a compile job. Thinking and dreaming review, challenge, and replay. That is where stale claims get caught.

**KVA is traffic control.** It says how an agent should move: forming vs alive vs exit. When many pages miss the same turn (accidents), KVA does not add a new status stamp. It changes the navigation rules — the schema — so the next compile lists that miss. Same Open/Closed pin: extend the checklist, do not rewrite the engine for each accident.

**Agents keep signals current**, like an open-source project: branch, review, merge. A `kva` or `growth` field that nobody updates is an accident. The fix is the next PR on that page, not a bigger enum.

**Signals stay small.** Declared: short KVA set, protostar for early ideas, work hub for active effort, exit page for a dead end. Inferred where cheap: missing required edges, broken paths, current_branch. No fifth “needs expansion” flag.
