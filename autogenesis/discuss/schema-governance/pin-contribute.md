## Content

A skill can extend SCHEMA in its own process-memory Atlas, or in a host Atlas it writes into.

**Pin:** both. Skill-owned stores may extend locally. Host install is an explicit, compile-checked contribution.

Set aside: never install into a host; always merge into one host SCHEMA; silent hand-edit of any SCHEMA.
