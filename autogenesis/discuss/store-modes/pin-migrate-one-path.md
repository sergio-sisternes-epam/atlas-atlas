## Content

Operator pin, 2026-09-10: one Atlas path **migrate** owns every store move.

The living relocate (`references/atlas` → `.atlas/<id>/`) stays a mode of that path.

Dedicated ↔ shared is another mode of the same path. The card must name the mode. Missing mode is incomplete Enter, not a guess.

Strategy migrate still changes `atlas_id`, rewrites the gitlink, and writes mesh `strategy`. It does not dual-write two stores.
