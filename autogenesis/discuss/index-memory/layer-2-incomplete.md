## Context

Second 1-by-1 after pin A (every folder `index.md` is STM). The human chose incomplete indexes so that unlisted pages are long-term memory.

## Decision

Layer 1 is whatever *is* listed in folder `index.md` files. Layer 2 is `atlas search` over concept pages that are *not* listed there. That is the deeper recall effort.

Folder indexes are therefore working sets, not complete inventories. New memories still enter the owning folder index (P2). Forget, later, is dropping a line without deleting the page.

## Compile consequence

Today `index_md_present` demands the file. The contract also names `index_md_listing` as completeness of children. Completeness cannot survive this pin. The next live choice is the exact compile rule.

## Outcome

P8 is alive as incomplete-index LTM. Forget stays parked. Order-as-frequency is now possible, because the list is allowed to be a subset.
