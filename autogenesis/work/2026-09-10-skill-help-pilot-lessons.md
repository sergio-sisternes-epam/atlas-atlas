## Content

A clear explanation can still omit a supported option. The storage walkthrough
favoured a dedicated repository until the user pointed out that a branch in an
existing repository is also a good starting point. Future Atlas storage help
should show both choices without imposing the assistant's preference.

An alive knowledge page is not proof of current capability. The historical
reusable-schema discussion is alive but says init/schema do not exist; the
installed skill supports both. Help needs source applicability as well as
traffic/status metadata. A separate installed-versus-checkout registry
difference reinforces this: configure exists in the checkout but not in the
installed root loaded here.

A conversational rehearsal can reveal an omission without proving a shipped
capability. Preserve the original feedback and its limits; do not turn a
polished answer into a claimed successful runtime test or repeated pattern use.
