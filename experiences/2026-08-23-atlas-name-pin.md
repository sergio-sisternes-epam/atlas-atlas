# 2026-08-23 pin: Atlas

## Decision

The rebooted skill that succeeds `okf-wiki` is named **Atlas**.

## Rationale (from session)

Atlas was selected after evaluating:

- Codex (strong on compiled source-of-truth, weak on modularity, mild OpenAI collision)
- Memory (too narrow and overused)
- Library (clear but plain)
- Archive, Vault, Garden, Lattice, Nexus, Tome, Summa, etc.

Atlas best holds the intersection of:

- compiled / authoritative knowledge (Codex strength)
- modular, navigable structure (graph / progressive disclosure)
- breadth beyond pure memory (experiences + designs + recipes + requirements + project knowledge)

## Scope the name is intended to cover

- Skill long-term memory and operational recipes (autogenesis and other skills)
- Project knowledge graphs (requirements, design decisions, system understanding) as single source of truth
- Durable, OKF-conformant, modular knowledge substrate


## Status

Name pinned. Design path remains open; formal plan and remaining pins still to be completed and approved. No implementation in this turn.
