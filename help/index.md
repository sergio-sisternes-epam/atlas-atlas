# Atlas help

Curated explanations and instructions grounded in source references and linked
Atlas knowledge. This first set covers visual exploration with Cartograph;
it is not an exhaustive registry of Atlas operations.

- [What is Cartograph?](cartograph.md) - Understand the visualiser and when to use it.
- [Open Cartograph in Copilot](open-cartograph.md) - Use the Canvas menu or ask the agent.
- [Install and open Cartograph](install-and-open-cartograph.md) - Explicit, scoped setup with APM.

These articles use the existing `document` type. The proposed `atlas-help`
schema and runtime `help`, `getting-started` and `visualise` paths are not
installed merely by publishing knowledge pages. Their design is tracked in
the [help pilot](../autogenesis/work/2026-09-10-skill-help-pilot.md).
Check each article's applicability and sources before using operational advice.
