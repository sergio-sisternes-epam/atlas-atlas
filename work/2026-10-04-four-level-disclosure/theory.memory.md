## What happened

Sergio locked a four-level write and recall model for Atlas memory.

Index is the hot cue list of schemas that are easy to find. He first called this short-term memory, then corrected it: these are active memories that are easy to find. Long-term memory is what fell off the index. OKF already treats index.md as a reserved directory listing for progressive disclosure, not as a concept page. An index that tries to be a table of contents fails; it is an entry point.

Schema is the high-level grouping of related gists. A folder may hold more than one schema when the subject changes. The rule is not one schema.md per folder. Type suffixes are the search handles: schema pages use `.schema.md`, gist pages use `.gist.md`, and memory pages use `.memory.md`; reserved `index.md` and `hub.md` stay unsuffixed. These suffixes are required even when names would not collide.

Gist is a semi-detailed summary of a group of memories. Memory is the detailed sequence of events and feeds both gist and schema. A change or a contradiction in a memory cascades up to the gist and the schema. Same-level links are legal: schema to schema, gist to gist, and memory to memory, including across clusters.

On this store the episode type is page, not memory. The page is the memory.
