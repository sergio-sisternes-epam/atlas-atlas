## What happened

Six counters were engaged and kept. They are constraints on the write model, not dead branches. Conflicting schemas hurt recall. Overlapping schemas can catastrophically interfere unless a large prediction error splits them. An index that lists everything is a failed table of contents; split around an entry-point budget near 25. Four-hop retrieval and two-level hierarchies pull in opposite directions, so recall must stop when a level already answers. Cowan's four chunks are laboratory short-term memory, so the index must not be named as that capacity. One schema per session fails when the subject changes.
