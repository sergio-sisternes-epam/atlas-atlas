## Content

This page is the schema: the high-level grouping of the related gists in this folder. The installed contract cannot express type schema. SCHEMA.json has no atlas_release and no memory.layers, so compile classifies the store as shipped beta, whose grouping type is frame. Type schema belongs to the current shape, which is written only on CONTRACT.json stamped 0.13.0-beta.3 or 0.13.0-beta.4 with layers schema, gist, memory. Using type schema here would invent a type the engine does not enforce. Type suffixes are the search handles: schema pages use .schema.md, gist pages use .gist.md, and memory pages use .memory.md. The reserved index.md and hub.md stay unsuffixed. These suffixes are required even when names would not collide.

The schema groups three gists: the locked theory, the counters that stay engaged, and the evolve-areas conclusion. A folder may hold more than one schema when the subject changes. This discussion did not change subject, so one schema is correct. The live compiler still expects exactly one frame per gist-bearing folder, and on this store that check is informational because the memory rung is absent. That is the one-schema-per-folder concern the objective is meant to fix, not a second schema invented for this filing.

Same-level schema links are allowed once more than one schema exists. None are required inside this single-subject folder.
